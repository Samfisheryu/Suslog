# Agent Working Rules

## Collaboration

- Before making product, UI, architecture, or code changes, discuss the intended design and implementation approach with the user first.
- Do not edit project files until the user explicitly approves the proposed direction or asks to implement it.
- If the user is asking for analysis, planning, design discussion, or options, answer with recommendations only and do not modify files.
- Small inspection commands are allowed for understanding the project, but any file edits must be preceded by a clear explanation of what will change.
- Keep changes scoped to the agreed design. If a new decision or tradeoff appears during implementation, pause and discuss it before continuing.
